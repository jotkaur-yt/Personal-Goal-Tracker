GOALSPACE — PERSONAL GOAL TRACKER (BEIGE EDITION)

Open index.html using VS Code Live Server.
Pages: Login, Create account, Dashboard, Manage goals, Progress, Calendar, Project.
The Project page displays the Mindmesh group and allocation details from the supplied CSE326 Section K3P26SP file.

Features: browser-local demo account and goal storage; add/edit/delete goals; search/filter; dashboard and progress; compact month calendar showing goal deadlines.

This is a front-end college demo only. Credentials and goals are stored in localStorage, not securely on a server. Do not use a real password.
